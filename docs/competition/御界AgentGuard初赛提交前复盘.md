## 一、开发计划完成情况

| 策划案阶段 | 已实现并可展示 | 计划内待验收 |
| --- | --- | --- |
| 阶段一：透明授权与最小权限 | 活动提交前预览日历、共享文件和通知的操作范围；可移除非必要文件更新，权限随任务一起缩小；任务护照限制工具、参数、有效期和使用次数；支持同任务核对脱敏 TXT 与 CSV | 任意 Agent 的工具扫描、敏感字段按权限解锁，以及开放格式文档处理，仍处于规划阶段 |
| 阶段二：运行时守护 | 后端网关执行放行、确认、阻断三态；批准、拒绝、过期取消及防重复执行；审批可看文件差异和通知范围，目标文件变化会使旧审批失效；支持故障熔断、模拟快照恢复、时间线和脱敏证据包 | 审批中修改参数尚未实现，须重建任务；状态每 4 秒轮询；当前恢复适用于模拟工作区。正式登录、持久化及真实系统接入属于后续工作 |
| 阶段三：评测和改进 | 本地批量回放、逐例结果和副作用核对，前端可导入报告并显示声明来源；另有 8 条 AgentArts 评估种子和导出文件 | 策划案要求的 60 条独立人工标注样本、三组基线、指标报告、事件一键转用例和 AgentArts 平台正式评估都待完成 |
| AgentArts 编排与部署 | 真实控制台已搭建六节点工作流。业务规划、内容隔离、行为守卫三个模型角色及证据组装代码节点已试运行；普通活动和外部资料风险两组虚构案例全链路成功。后端桥接已实现且通过本地模拟响应测试 | 工作流版本发布、运行时部署、真实 API 联调；新版三工具 MCP 的云端接入、规则说明的知识资产引用和平台评估 |
| 阶段四：拓展 | 已验证活动组织原型，可用你们组织的比赛验证改期通知、志愿者排班等具体任务 | 更多工具、权限模板、SDK、组织账号及正式在线服务。先用真实组织者反馈确定扩展方向 |

主流程可以演示：组织者提供活动资料 → 核对时间、地点、匿名排班及拟通知人数 → 确认参数并签发任务护照 → 按风险执行或暂停审批 → 查看轨迹与恢复结果。业务工具使用内存模拟日历、通知和共享文件。

## 四、初赛交付清单

1. **官方 Word 表及上传字段**：作品简介和创新点、队伍介绍、真实问题与应用场景、Agent 分工和工作流、模型与资产选择。用最新状态更新 [`初赛填表草稿`](../initial-submission-draft.md)，其中原有测试数字需换成当前实测值。
2. **AgentArts 证据及完整视频**：保存画布、节点配置、运行记录、结构化输出。上线联调后，用同一个运行记录关联前端任务与平台日志，再录制正常、确认和阻断主线，恢复可放独立镜头。视频字段、格式、时长和大小按登录后的报名页面核对，录制可参考 [`初赛 Demo 脚本`](../initial-demo-storyboard.md)。
3. **应用价值证据**：优先做出可追溯的比赛组织真实案例和首批评测，尽量完成项目计划的 60 条和三组对照。以同一批样本分别报告正常任务成功、风险阻断、误报和恢复，保留失败样本。
4. **最终归档及回执**：版本、Word、视频和按报名页允许提交的附件统一核对。队长保存最后一次上传的成功回执。本次公开查询未核实队伍适用的最终作品上传截止时间。组委会邮件中的 12 月 9 日 17:00 对应代金券资格核验。见 [华为作品上传操作指导](https://e.huawei.com/cn/talent/news/#/details?consultationId=5970)。

按已提供的赛题规则，初赛创新性占 60%，应用价值占 40%。创新部分优先呈现同一任务缩小授权、审批绑定参数、失败后可恢复；应用价值部分用组织者记录和实测结果说明实际效果。中国总决赛还需备可在线交互 Demo、Agent 设计文档和社区分享帖截图，自定义 MCP 说明随实际接入整理。

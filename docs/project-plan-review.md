## 已完成的本地阶段

- 新增只读 `POST /api/activities/preview`，复用与执行链相同的确定性规则，但使用隔离的临时护照注册表，不污染真实任务、审批和审计状态。
- Live 页面新增按当前参数生成的授权/风险卡片；修改输入后不显示旧预览，避免把过期范围当成当前授权。
- AgentArts 可见的只读 MCP `preview_activity` 与网页预览共用规则计算；模型提供的 `source_trust` 仅是预览假设，不构成执行授权。
- Live 模式新增单份 TXT/CSV 参考资料输入，限定格式/大小/CSV 结构；只保留哈希、来源、列名和风险摘要，不保留正文或行值，不向 AgentArts 传送资料正文。加入虚构演示资料与外部指令不能覆盖用户收件人的端到端测试。
- 新增资料只读核对：CSV 行数与拟通知人数不一致时给出人工核对建议；资料或人数变化后旧建议失效。未把外部资料行数当作授权，也未自动更改任务参数。
- 用户可在提交前取消“更新共享活动文件”；预览、规划、任务护照与执行同步缩小为日历和通知两步。测试覆盖 Agent 事后补加文件请求时被 `TASK_PASSPORT_VIOLATION` 阻断。
- 外部资料仅向云端规划器传递后端生成的格式、行数和风险布尔信号，不传文件名、正文、列名、人员值或哈希；三角色工作流搭建包已准备，尚待真实平台验证。
- 后端 66 项、前端 29 项自动化测试及前端构建通过。11 月 11 日当前版本 MCP 已重建 ARM64 容器并通过 `initialize`、双工具 `tools/list` 及取消文件更新后的 `preview_activity` 调用；不等于云端 AgentArts 验证。Chrome 华为云登录页现可打开，但当前浏览器仍未登入控制台。

## 下一阶段的真实优先级

1. **把辅助建议继续做实**：当前可核对人数，但还不能从资料中形成可审查的排班或活动安排建议；这类建议必须由用户明确采纳，不能自动扩权。PDF 解析及真实名单接入先不承诺。
2. **补评测证据**：由评测负责人建立可回放的 60 条标注样本及分母清晰的指标；合成看板只保留为 UI 演示。
3. **补 AgentArts 证据**：在控制台真正搭建三角色工作流，调用只读 MCP 预览，保存画布、试运行、Trace 和评估截图。正式 API 调用前先核实代金券适用范围；不擅自启用可能计费的服务。
4. **补可信在线演示**：目前演示 API 无认证，不能直接公开部署。先实现会话身份和审批归属校验，再考虑在线地址。
5. **补真实需求**：选择可接触的活动组织者或小型团队，做结构化访谈与脱敏任务试用；只报告实际记录到的数据。

目前最强的可展示点是“任务可完成，同时高影响操作暂停、越权被阻断、失败可恢复”。最大短板不是页面数量，而是**真实资料的有用处理、AgentArts 实际使用、评测证据和用户验证**。这些补齐前，不应宣称已达到策划案完整 MVP。

## 本轮完成

- 新增只读 `POST /api/activities/preview`，复用与执行链相同的确定性规则，但使用隔离的临时护照注册表，不污染真实任务、审批和审计状态。
- Live 页面新增按当前参数生成的授权/风险卡片；修改输入后不显示旧预览，避免把过期范围当成当前授权。
- AgentArts 可见的只读 MCP `preview_activity` 与网页预览共用规则计算；模型提供的 `source_trust` 仅是预览假设，不构成执行授权。
- 后端 51 项、前端 26 项自动化测试及前端构建通过。MCP 运行时协议/镜像在本轮修改后仍需复验，不能沿用旧版结果。

## 下一阶段的真实优先级

1. **补真实输入链路**：从自制、脱敏的 TXT/CSV 活动资料开始，做来源标签、字段白名单和异常指令样本。PDF 解析及真实名单接入先不承诺。
2. **补评测证据**：由评测负责人建立可回放的 60 条标注样本及分母清晰的指标；合成看板只保留为 UI 演示。
3. **补 AgentArts 证据**：在控制台真正搭建三角色工作流，调用只读 MCP 预览，保存画布、试运行、Trace 和评估截图。正式 API 调用前先核实代金券适用范围；不擅自启用可能计费的服务。
4. **补可信在线演示**：目前演示 API 无认证，不能直接公开部署。先实现会话身份和审批归属校验，再考虑在线地址。
5. **补真实需求**：选择可接触的活动组织者或小型团队，做结构化访谈与脱敏任务试用；只报告实际记录到的数据。

目前最强的可展示点是“任务可完成，同时高影响操作暂停、越权被阻断、失败可恢复”。最大短板不是页面数量，而是**真实资料输入、AgentArts 实际使用、评测证据和用户验证**。这些补齐前，不应宣称已达到策划案完整 MVP。

## 已完成的本地阶段

- 新增只读 `POST /api/activities/preview`，复用与执行链相同的确定性规则，但使用隔离的临时护照注册表，不污染真实任务、审批和审计状态。
- Live 页面新增按当前参数生成的授权/风险卡片；修改输入后不显示旧预览，避免把过期范围当成当前授权。
- AgentArts 可见的只读 MCP `preview_activity` 与网页预览共用规则计算；模型提供的 `source_trust` 仅是预览假设，不构成执行授权。
- Live 模式新增单份 TXT/CSV 参考资料输入，限定格式/大小/CSV 结构；只保留哈希、来源、列名和风险摘要，不保留正文或行值，不向 AgentArts 传送资料正文。加入虚构演示资料与外部指令不能覆盖用户收件人的端到端测试。
- 新增资料只读核对：CSV 行数与拟通知人数不一致时给出人工核对建议；资料或人数变化后旧建议失效。TXT 出现相互冲突的时间/地点、CSV 出现多个时段列时停止生成对应草案并提示核对。未把外部资料行数当作授权，也未自动更改任务参数。
- 用户可在提交前取消“更新共享活动文件”；预览、规划、任务护照与执行同步缩小为日历和通知两步。测试覆盖 Agent 事后补加文件请求时被 `TASK_PASSPORT_VIOLATION` 阻断。
- 脱敏 CSV 的匿名排班可由用户明确采纳；后端重新验证哈希、人数和每行时段，生成只含行号与时段的共享文件内容，并在人工审批通过后模拟写入。哈希不匹配或排班不完整时拒绝创建任务，不会按未核对的资料执行。
- 外部资料仅向云端规划器传递后端生成的格式、行数和风险布尔信号，不传文件名、正文、列名、人员值或哈希；三角色工作流已在真实平台完成两组虚构案例的全链路试运行。
- 可选访客隔离模式为每个随机 Cookie 建立独立的任务、审批、审计及模拟工具运行空间，关闭 `/core/*`，限制同时保留 64 个会话并回收闲置一小时的会话；前端 Live 请求携带 Cookie。它只用于多人模拟演示，不代表真实身份认证。
- Live 模式新增服务端脱敏证据包：只导出事件类型、策略决定、审批指纹、工具名称和来源哈希等安全事实；事件链与当前策略文件均有 SHA-256 摘要，离线脚本可检查授权到执行的顺序及与另存根摘要是否一致。它不含正文/收件地址，也不等于不可抵赖签名。
- 审批页新增后端计算的影响预览：共享文件显示行数、内容差异及前后版本摘要；通知显示目标地址和人数。文件批准前复核目标摘要，变化则使审批失效、保留较新版本并记录前序步骤需人工核对；不把模拟内存锁说成真实系统事务。
- 新增 [`config/policy_guidance.json`](../config/policy_guidance.json) 版本化规则说明；Live 权限预览显示处理建议及内部规则引用，MCP `explain_policy` 按原因码只读查询，未知原因码拒绝。它不构成授权，也不等于已在 AgentArts 平台创建知识库。
- 后端 96 项自动化测试通过；前端此前有 33 项测试、构建及 Ruff 检查通过，本次未重跑。11 月 11 日旧双工具 MCP 版本已通过 ARM64 容器内协议复验；新增规则解释后的三工具版本尚未重建容器或完成云端验证。用户已兑换代金券并开通 AgentArts 体验版；券的具体适用范围仍待核查。

## 下一阶段的真实优先级

1. **把辅助建议继续做实**：当前已可在同一任务中分别核对 TXT 策划书与 CSV 报名表，采纳时间地点和匿名排班草案，并经审批写入模拟共享文件。仍未验证真实名单或实际接收对象的授权，开放式策划书提取也未实现。PDF 解析及真实系统接入先不承诺。
2. **补评测证据**：由评测负责人建立可回放的 60 条标注样本及分母清晰的指标；合成看板只保留为 UI 演示。
3. **补 AgentArts 证据**：真实三角色工作流和两组试运行已经完成；下一步保存画布、试运行及调用详情截图，提交版本后验证运行时 API，再接入只读 MCP 预览和平台评估。正式 API 调用前先核实代金券适用范围；不擅自启用可能计费的服务。
4. **补可信在线演示**：访客会话隔离已完成，但无真实身份认证、持久化、限流与成本保护；先保持模拟工具与单进程演示，再考虑在线地址。真实系统或云端付费调用不能直接暴露在匿名演示模式中。
5. **补真实需求**：选择可接触的活动组织者或小型团队，做结构化访谈与脱敏任务试用；只报告实际记录到的数据。

目前最强的可展示点是“任务可完成，同时高影响操作暂停、越权被阻断、失败可恢复”，并且三角色分析已在 AgentArts 上用虚构案例跑通。主要短板是**在线云端链路、独立评测证据和真实用户验证**。这些补齐前，不应宣称已达到策划案完整 MVP。

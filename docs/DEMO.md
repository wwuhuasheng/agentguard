# 演示步骤

前端默认是 Mock 模式，适合离线讲解交互。比赛联调时可切到 Live 模式，让请求经过 FastAPI、策略网关和 Mock 工具。不要把 Live 里的内存工具说成真实邮件、日程或共享盘。

## 准备

### Mock

```powershell
cd frontend
npm install
npm run dev
```

### Live

先启动根目录 API，再把 `frontend/.env.local` 设置为 `VITE_DATA_MODE=live`：

```powershell
python -m pip install -e ".[api]"
uvicorn backend.api.server:app --reload --port 8000
```

## Live：真实输入参数链路

在任务控制台填写未来活动时间、地点、`example.org` 域名下的接收地址、接收人数和通知内容，先点击“预览本次权限与风险”，观察操作的预估决策。保留“同时更新共享活动文件”时，提交后到执行轨迹查看三角色规划证据、任务护照、日历工具请求和文件更新审批；批准文件更新后，12 人通知可自动完成。取消该选项再运行一次，可看到预览、任务护照和执行轨迹都不含文件更新，且无需文件审批；若人数改为 40，通知仍需审批。全部为内存模拟工具，并非真实发送。Live 模式默认使用本地离线规划器，不能作为已接入 AgentArts 的证明。

可同时上传仓库内的 [`activity-plan-synthetic.txt`](../examples/activity-plan-synthetic.txt) 和 [`activity-roster-synthetic.csv`](../examples/activity-roster-synthetic.csv)（均为虚构样例），也可把 TXT 换成 [`activity-reference-injection.txt`](../examples/activity-reference-injection.txt) 展示异常来源。每种格式最多一份、每份最多 32 KB；同格式重选会替换旧文件。正常策划 TXT 会提取时间、地点草案，并显示各字段来自资料的行号；只有用户点击“核对后填入时间地点”才修改表单，仍须自己设定通知对象并核对权限。异常 TXT 展示疑似越权指令所在行号，但不会返回原文或改写结构化收件地址；CSV 展示姓名、手机号列被排除，行值不进入任务记录。轨迹页能分别查看两条 `SOURCE_INSPECTED` 摘要；给云端规划器的只是合并后的格式、行数和风险布尔信号。检测规则只是启发式，不能将“未命中”解释成安全。演示不可上传真实名单或私密文档。

上传 CSV 后点击“核对资料与通知人数”：样例有 2 行，默认拟通知 12 人，页面会提示核对差异、敏感列，并基于 `availability` 给出匿名的上午/下午排班草案（只显示行号，不显示姓名电话）。把人数改成 2 后，旧建议立即失效；重新核对并对照原始名单和人员意愿，点击“核对后采纳”。提交任务后，后端重新计算 CSV 哈希、人数与排班完整性；服务端只接受未变更且所有时段明确的草案。共享文件更新进入人工审批，**批准前不会写入排班**；批准后写入模拟文件的只有“报名表第 N 行 → 上午/下午”，姓名和电话不会进入文件。拒绝或超时则取消更新。未采纳时仍只展示建议，不自动写入文件、修改人数或发送通知。答辩时可把 TXT 信息草案、CSV 排班、权限预览、审批和轨迹串成一次演示。两份资料能在同一任务中分别处理，但目前仍只提取固定格式的时间地点和标准时段，不能解析任意开放式策划书。

任务完成后在执行轨迹点击“导出脱敏证据包”。向评委展示事件根摘要、工具执行之前的策略与审批记录，并用 `python scripts/verify_evidence.py 下载文件.json` 复核。包内不含通知正文或收件地址；根摘要须另行记录才能检测日后替换整个文件。此证据来自本地模拟工具，不代表 AgentArts 云端 Trace。

在文件审批页还可展示“当前模拟文件→拟写入内容”的逐行差异和版本摘要。若要演示陈旧审批阻断，可在另一条本地任务或开发测试中先更新同一模拟文件，再批准旧请求：旧审批转为“目标已变化”，不会覆盖新文件；轨迹同时提示此前创建的日历等步骤需人工核对。正常演示不必人为制造这个冲突。

以下四个预置场景仅在 Mock 回放中选择；后端仍保留对应接口供自动化回归。

## 1. 正常放行

任务控制台选择“正常放行”并启动。查看来源、工具请求、`ALLOW`、策略证据和执行结果。

## 2. 人工审批

选择“人工确认”并启动。40 人通知触发 `CONFIRM`。在人工审批页检查范围、规则和完整参数；批准后工具执行一次，拒绝则不执行。审批 60 秒过期，过期后批准也不会执行。重复决策返回冲突。

## 3. 越权阻断

选择“越权阻断”。外部不可信指令请求把敏感字段发给外部邮箱。查看 `BLOCK` 和命中证据；确认没有对应的工具执行事件。前置的低风险日程可以成功，阻断只针对危险请求。

## 4. 熔断恢复

选择恢复场景并批准共享文件更新。后端首次模拟执行失败，随后继续失败两次；达到三次阈值后熔断、取消待发通知，并把共享文件恢复到操作前快照。比较前后内容并导出轨迹；Live 模式提供脱敏证据包，Mock 模式提供本地回放 JSON。

## 5. 评测看板

先在项目根目录运行 `PYTHONPATH=. .venv/bin/python scripts/replay_local_eval.py --output .runtime/local-replay-report.json`，再在评测页的“本地回放报告”导入这个 JSON。页面显示逐例状态、审批、模拟副作用和报告对应的代码/策略版本；导入只在浏览器本地进行。这是 8 条虚构样本的**实际本地回放结果**，不能当成 AgentArts 模型准确率或真实比赛试点效果。

下方 60 条仍为前端合成展示样例。可查看公式、切换类别、搜索、翻页并导出；故意保留失败样例用于展示边界，不声称全部通过。

## 答辩说明

可以展示确定性策略、人工确认、审计证据、失败熔断和快照恢复。当前后端是演示编排层；可选访客会话只隔离模拟任务，没有真实登录或持久化数据库，每个 API 进程重启后状态清空。

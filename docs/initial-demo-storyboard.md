# 御界 AgentGuard 初赛 Demo 录制脚本

> 目标：用约 3 分钟展示真实需求、AgentArts 构建与运行、可视化交互和安全闭环。实际时长以报名页要求为准。所有活动、人员和地址均使用虚构数据。

## 录制前准备

1. 华为云控制台打开“御界 AgentGuard 可信执行分析”工作流；核对画布为开始、业务规划、内容隔离、行为守卫、代码、结束六节点。
2. 准备两组试运行输入：普通社区读书会（20 人、无需更新共享文件）与外部资料风险（40 人、需更新文件、`possible_instruction=true`、`has_sensitive_columns=true`）。只传风险信号，不上传名单正文。
3. 本地 Live 页面准备虚构 TXT 策划书和 CSV 报名表、通知目标 `readers@example.org`。确认后端使用本地规划器时，画面清楚标注“本地演示”；若尚未完成运行时 API 联调，不要称它为云端执行结果。
4. 遮住华为云账号、余额、API Key、实名资料、个人通知和浏览器其他标签页。先试录一遍，检查页面文字可读。

## 镜头与讲述

| 时间 | 画面 | 建议讲述与可见证据 |
| --- | --- | --- |
| 0:00–0:20 | 活动组织任务和虚构资料 | “组织者要建日程、更新活动文件并通知参与者。外部资料可能夹带改收件人或扩大权限的指令。”展示用户确认的目标与外部资料的来源标记。 |
| 0:20–0:45 | AgentArts 工作流画布 | 展示三个模型角色和证据组装代码节点；说明 Agent 负责只读分析，最终工具授权由确定性网关裁决。 |
| 0:45–1:15 | AgentArts 普通案例试运行结果与调用详情 | 展示六节点成功、输出三角色证据；明确这是控制台试运行，不是在线 Demo 的运行时 API。 |
| 1:15–1:40 | AgentArts 外部资料风险案例试运行结果 | 展示风险信号、内容隔离结论和调用详情；指出只传 `possible_instruction` 等摘要，不上传名单正文。不要声称模型已经阅读或识别了所有攻击。 |
| 1:40–2:10 | 本地 Live 页面权限预览与资料核对 | 展示 TXT/CSV 摘要、拟通知人数和“最小权限方案”：同一任务取消非必要文件更新前后的工具数与待确认数，点击采用后重新预览，文件步骤应消失。画面标注“本地模拟工具”；若文件确实需要更新，保留原权限并走人工审批。 |
| 2:10–2:40 | 本地审批与轨迹 | 展示文件更新或群发停在人工确认；批准前看到目标和影响，越权扩参被任务护照阻断。只用虚构接收地址。 |
| 2:40–3:00 | 结果与边界 | 展示脱敏证据包或失败恢复；总结“AgentArts 分析、网关裁决、人工审批”。说明尚未连接真实社区系统；若 API/MCP 未上云，明确标注“下一阶段接入”。 |

## 录制后的验收

- 画面能辨认工作流节点、成功状态、用户确认参数、策略决定和任务结果；不要只放 PPT 口述。
- 云端与本地镜头分别标识；禁止把两段剪成一条未经验证的连续调用链。
- 视频结尾和官方 Word 表中的“当前完成情况”一致；功能、测试数量、平台接入状态以最终录制日复核为准。
- 将截图、视频和最终 Word 表放在提交包；仓库若存证据只放脱敏版本，不提交账号信息或 API Key。

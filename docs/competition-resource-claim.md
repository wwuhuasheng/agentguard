# 初赛材料上传与赛事资源领取清单

依据：队长提供的“创新赛赛题 1、赛题 2 参赛同学”邮件。此清单用于办理事项，**不代表已经上传、已进入白名单或已领取积分**；以报名页和领取页实时状态为准。

## 顺序与截止点

1. 核实队伍已完成创新赛赛题 2 报名并成功组队。
2. 已在本机找到「作品信息收集表」Word 模板并曾生成项目草稿，但 2026 年 11 月 10 日检查时原 `outputs` 路径已无该 Word 文件。请队长确认自己持有的最新版，按报名记录填齐学校、队伍、老师、队员、联系方式及团队合照后再上传；若文件丢失，用 `initial-submission-draft.md` 重建。首次上传不要求完整作品，也不要求 Demo 链接；未完成的 AgentArts 云端环节应明确标为计划，不得声称已经部署。
3. 队长或任一队员在报名页面完成至少一次**有效**作品材料上传，并保存提交成功页面或回执。可多次更新；初赛评分以作品上传截止前最后一次提交为准。
4. 组委会每周三 17:00 导出符合条件的名单，周六 10:00 前更新领取白名单。**2026 年 12 月 9 日 17:00 是代金券资格核验的最后一次导出时间**；这不是初赛评分材料最终截止时间。
5. 白名单更新后，每位符合条件的参赛队员使用**本人**已实名认证的华为云账号，在[积分领取入口](https://gallery.developer.huaweicloud.com/gallery/competition?type=innovation)授权绑定 ICT 大赛报名账号并领取 350 积分，每人限一次。不可代领、转让或把积分直接当成同额人民币。
6. 到[华为云开发者成长中心](https://developer.huaweicloud.com/grow?ggw_kfz)核对积分到账并兑换。兑换前逐项检查券种、适用服务、地域、有效期、是否抵扣按需用量及超额扣费方式；各队员积分按个人账号发放，不能假设可合并到同一云账号。

## 上传前核对

- [x] 赛题 2 官方 Word 模板已在本机取得，项目内容已填入副本；仍需在报名页面复核当前模板版本和附件要求。
- [ ] 队伍名称、学校、指导教师和队员信息与报名记录一致。
- [ ] 赛题明确写为创新赛赛题 2，不混入其他赛事的 AgentArts 赛题。
- [ ] 已完成能力与待实现能力分开陈述，未把本地模拟说成真实 AgentArts 云端运行。
- [ ] 文件中没有 API Key、密码、身份证号、真实活动参与者名单或未授权数据。
- [ ] 至少一名队员上传成功，并保留平台回执。

## 领取与费用边界

AgentArts 体验版可免费用于开发和试运行；赠送模型 Token 不覆盖发布后通过 API 发起的正式调用。赛事积分兑换券的覆盖范围尚需在成长中心页面逐券核对。在确认券能覆盖 MaaS、运行时及必要依赖服务前，不自行购买套餐、不充值、不启用不必要的按需服务。
